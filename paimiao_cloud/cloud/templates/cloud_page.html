派喵云同步 · 数据传输指引

在开启派喵云同步前，请先阅读本说明。本说明将告知您哪些数据会离开本机、传输至何处，以及如何停止传输。

一、功能说明

本功能用于将 Evo 已在本机识别的战绩记录上传至派喵服务器，以便您在微信小程序「派喵」中查看。

此外，您也可以主动把已经上传的记录取回到本机（例如换了电脑或重装 Evo 之后）。取回只在您点击按钮时发生，不会自动执行。

二、上传的数据范围

  • 对局时间（结束时间；如能获取，还包括开局时间）、游戏模式、地图及使用的传奇
  • 名次、击杀、助攻、击倒、伤害、参与度，以及小队总击杀
  • 救援队友次数、复活次数
  • RP 变化及存活时长
  • 段位信息：段位名称（如「钻石」）、段位等级（如「II」）、段内排位点数及换算后的总分。
  • 您的游戏内玩家名
  • 同队队友的玩家名、传奇、击杀数、助攻数、击倒数、伤害、存活时长及救援次数（该等信息属于战绩记录的组成部分）

三、不会上传的数据

  • 不上传截图。Evo 截取的图片仅保留在本机，不会对外发送任何字节
  • 不上传数据库文件、账号密码及本地文件路径
  • 不上传电脑名称、硬件信息，以及除 IP 地址之外的任何设备指纹信息
  • 不会改动本机数据库。读取过程采用只读方式，不会对数据库产生写入影响

唯一的例外是「从云端取回」：该操作会把您本人已上传的战绩写回本机数据库。 它只新增、不修改也不删除任何已有记录，本地已经有的会自动跳过， 并且在写入前会自动备份一次数据库。

五、数据使用目的、存储位置及访问权限

派喵项目维护者（以下简称“维护者”）仅为下列目的处理您的战绩数据：

  1. 提供战绩查询服务：将战绩与您的微信账号绑定，供您在微信小程序「派喵」中查看。
  2. 匿名统计分析：在去标识化或匿名化处理后，用于生成传奇选取率等汇总统计，以改进服务。该统计不会用于识别或追踪特定个人。

上传目标为派喵小程序的服务器（{{ view.server_host }}），由维护者负责维护。在可识别个人层面，相关战绩与您的微信账号绑定，仅您本人可在小程序中查看。Evo 原作者不参与处理，亦无法访问该等数据。除提供上述服务所必需外，维护者不会向无关第三方出售您的战绩数据。

六、关闭与停止处理

您可通过以下方式控制数据上传及使用：

  • 解除配对：立即停止全部上传。
  • 撤回同意：停止上传，并清除本机设备令牌及同步记录。
  • 关闭 Evo：不会执行上传。
  • 关闭匿名统计分析：在派喵小程序内选择「设置」-「关闭匿名统计分析」。关闭后，后续上传的数据将不再用于该目的。
  • 删除已上传的历史记录：在派喵小程序内选择「设置」-「删除云端用户数据」，该操作将删除您在派喵小程序服务器中存储的所有数据。

已上传至服务器的历史记录不会因本机操作而自动删除。如需删除，请按上述方式操作。

七、可选功能说明

本功能为可选项。未开启本功能时，Evo 的其他功能均可正常使用。除检查更新外，Evo 本身不会联网，此点未发生变化。

「从云端取回」同样是可选的，且需要您主动点击。未点击时不会发生任何取回行为。
