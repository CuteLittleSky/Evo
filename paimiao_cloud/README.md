## 本分支做了什么

1. **新增「派喵云同步」**（可选）：顶部导航第 4 项，把 Evo 识别出来的战绩同步到派喵小程序。电脑端出 6 位码，在派喵小程序「游戏战绩」里输入确认即可配对。
2. **更新检查改由派喵服务器下发**，安装包从 Cloudflare R2 下载；源代码链接、意见反馈入口改成本分支的。
3. **启动时弹一次非官方分支说明**，设置页底部常驻「关于本分支 / 第三方许可」卡片。
4. **关掉上游的「匿名统计」**：派喵版整条关掉——不弹提问、设置页不显示、一个请求都不会发。想恢复：启动前设环境变量 `EVO_PAIMIAO_TELEMETRY=0`。
5. **不显示上游的「关注我」**：想恢复：启动前设环境变量 `EVO_PAIMIAO_FOLLOW=1`。
6. **新增「主机模式」**（可选，设置页「画面来源」一栏）：用 OBS 的全屏投影把主机（Switch / PS5 / Xbox）的游戏画面投到电脑上的一块屏，Evo 直接截那块屏，识别规则一行不改。默认仍是「整屏（PC 游戏）」，PC 玩家的行为和上游一字不差。代码在 `cloud/obs/`，全部靠运行时注入，上游 0 字节改动。
7. **新增「大厅模式识别」**：在准备界面读出这一局是什么模式（排位、匹配、外卡、控制、子弹时间、团队死斗、机器人大逃杀等），自动记进 `matches.mode`，战绩页就能看到。读不准就留空，不猜；上游开局画面的判定仍然优先。代码在 `cloud/lobby_mode/`，同样全部靠运行时注入，上游 0 字节改动。
8. **地图回推**：开场横幅没拍到时，按开局时刻查地图轮换接口把地图补回来；拿不到数据一律静默降级——宁可空着，不写错图。

## 数据协议

使用云同步前必须先同意《派喵云同步 · 数据传输指引》（软件内「派喵云同步」页可随时查看）。
指引正文改了会要求重新同意，重新同意之前不会上传任何数据。

**会上传**：对局时间、模式、地图、传奇、名次、击杀、助攻、击倒、伤害、RP 变化、存活时长、你的玩家名、段位信息，以及队友的名字、传奇和对应数据。

**绝不上传**：截图、数据库文件、账号密码、文件路径、硬件信息。

数据按你的微信账号归属，只有你自己的派喵小程序会话能读到。

**不用这个功能就什么都不传。** 没有同意、没有配对、或关掉自动同步，都不会启动上传。
