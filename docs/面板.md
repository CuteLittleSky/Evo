# 页面（Evo 窗口里的面板）

改页面时读这份。改网页前先看当前 DSH 会话里有没有界面设计类的 skill（技能选择器里列的），有就加载照着做；没有就用现有的组件和样式（`style.css` 里的变量、`_legend.html` 这类已有片段），别另起一套视觉风格。

- 代码：`code/panel_app.py`（Flask），模板在 `panel/templates/`，样式、字体、脚本在 `panel/static/`
- 设计稿：`panel/prototype/Evo 界面设计.html`（双击用浏览器打开，会联网加载 React 和 Google 字体，只作参考；保持原样不改）。共 8 个画面：总览、战绩、设置、托盘与通知，各有黑夜和白天两版
- 两套主题用同一套页面 + CSS 颜色变量实现，支持"跟随系统"
- 正式面板不加载任何网上的内容；Evo 会联网的只有检查更新、一键更新和用户同意后的匿名统计（`telemetry.py`）
- **侧边栏**（2026-11-19 用户要求，照用户给的两张截图；`panel/templates/_side.html`，样式在 `style.css`"侧边栏"一节；代替原来顶部横着的那一行）：固定在窗口左边、不跟着内容滚动，内容在右边剩下的地方居中（最宽还是 1200）。看直播页没有侧边栏
  - 从上到下：EVO 标志（展开时右边是主题按钮）、"演示数据"（看演示数据时）、切换账号（2 个以上账号时）、导航（总览、战绩、数据、赛季、赛事；"设置"推到最下面，和上面几项隔开）、「Evo 占用」、最下面"« 收起"
  - **展开**（216 像素，默认）：图标和文字一行；**收起**（96 像素）：**只有图标，不写文字**（用户 11-19 先看了"图标在上、文字在下"的样子，要求收起时不显示文字），主题按钮挪到「Evo 占用」下面，切换账号变成一个人像按钮（点了先展开、焦点放到下拉框上），"演示数据"只剩一个点，"« 收起"变成"»"。「Evo 占用」收起时照样显示两个数字（是数据，不算文字说明）。按钮的位置、切换账号放侧边栏里都是用户 11-19 在两个方案里选的
  - 只有图标的地方（收起时的每一项，和展开时标志右边的主题按钮）：鼠标指上去、用键盘移过去时，右边马上显示名字（深色主题里是白底黑字的小块，反过来一眼看得出是提示；`data-tip` + 一块 `position: fixed` 的 `#side-tip`，挂在每一项上会被会滚动的侧边栏裁掉）。名字照样写在页面里留给读屏软件，不用浏览器自带的 `title`（要停一秒才出来、和自己的提示重复）
  - 收没收起记在 `localStorage` 的 `evo-side`，换页、重新打开窗口都保持；`base.html` 开头的脚本在画页面之前就加上 `side-collapsed`，不会先展开再收起。收起时每项 44 像素高，窗口最矮（640）也一屏放得下；放不下时侧边栏自己滚动
  - 选中那一项：底色一块（深色 `#1B1F29`，浅色白底加一圈细边），左边贴着窗口边一条红色竖条，`aria-current="page"`。从别的页面点过来，底色和竖条从上一页的那一项滑过来（"设置"和上面隔着空白，滑多远由脚本按实际位置量）
  - 点"收起 / 展开"：侧边栏的宽度和右边的内容一起过渡约 0.24 秒（`startViewTransition`，和切换主题一样：浏览器拍下前后两张图再过渡，页面本身只排一次版）；Windows 设置里关了"动画效果"时直接切换
  - 内容区"窄了就变成一列"这类规则（总览两列、统计数字几格、地图三格、设置页两列、赛季卡片、赛事列表……）改成按内容区自己的宽度算（`@container page`），不按整个窗口：侧边栏展开、收起时内容区宽度不一样。数字 = 原来的窗口宽度 - 两边留白 80。默认窗口（1280）展开时数据页的卡片是一列（内容区约 970，两列要 1020），收起后两列；战绩页的表要 900 宽，窗口窄于约 1220 且侧边栏展开时表格在卡片里横着滚（以前窗口窄于约 980 才滚）
  - 以前的宣传图、0.6.0 的实机示意图都是顶部导航的样子（`tools/feature_cards.py`），要不要重做由用户定
- **侧边栏下面的「Evo 占用」**（2026-11-15 用户要求；`panel/templates/_usage.html`，数字怎么量见 `docs/底座.md`"Evo 占用"）：先做成总览页"最近对局"下面的一张卡片，当天用户要求改放到顶部那一行、原来派圈助手按钮的位置；2026-11-19 改成侧边栏以后放在导航下面，每一页都有
  - 按钮：一张小卡片，上面折线小图标和"Evo 占用"，下面现在的 CPU、内存（Evo 全部进程合计；CPU 按整台电脑算，和任务管理器一样，用户定的）；侧边栏收起时只剩图标和上下两个数字（"Evo 占用""CPU""内存"留给读屏软件）。数字用等宽数字并留出宽度，按钮不跟着数字变宽变窄
  - 点了在侧边栏右边展开一块（不是弹窗，不挡页面；下边和窗口底对齐，`aria-expanded`；用 `position: fixed`，不然会被会滚动的侧边栏裁掉），再点、点外面、按 Esc 收起（Esc 收起后焦点回到按钮）。上面一行"Evo 占用"（原来右边还写着"算法和任务管理器一样"，11-15 用户要求删掉），下面两格，照"当前地图"格子的样子：
    - "现在"：CPU、内存，下面一行分开写"托盘 37 MB · 窗口 115 MB · 记录 210 MB"（没在记录写"没在记录"，用浏览器打开的面板没有窗口那一项）
    - "最近 N 局对局中（平均）"：每局一样重的平均 CPU、内存，下面一行"内存最高 236 MB"。原来后面还写着"同时整台电脑 CPU 58%"（想让玩家知道游戏占了多少、Evo 占了多少），11-15 用户看不懂，删掉了；整台电脑的 CPU 照样记在 `usage.json` 和日志里。还没有局时写"最近 10 局对局中（平均）"、两个"—"和"打完一局以后显示"
  - 页面打开一秒后问一次 `/usage`，之后每 2 秒一次，只换按钮和"现在"那一格的文字（`base.html` 的脚本）；窗口最小化时不问。第一次打开时 CPU 写"—"（要和一秒前比）。不用 aria-live（每 2 秒念一次太吵）。每打开一页量一次（约 5 毫秒，`panel_app.usage_card`，模板用到时才调用）

## 显示规则

- 段位和 RP 按游戏里的方式显示，如"钻石 I · 48 排位点数"：不显示分母、进度条和"距下一段还差"（每段要多少分不一样）
- 读不到的数据显示"—"
- 传奇名字前有小头像（战绩页自己和队友、总览页最近对局和传奇表现；2026-10-20 用户决定）：18 像素，单色、颜色跟随文字（原图是黑色的，深色主题下看不见），名字就在旁边，读屏软件跳过它；没有图标时（没认出、以后的新传奇）留出同样宽的空位，名字上下对齐。写法在 `panel/templates/_legend.html`，样式 `.legend-icon`
- 传奇头像的来源和许可：原图（Apex Legends Wiki 上的 SVG）放 `assets/legends/`，每个文件的许可不一样，写在那里的 `LICENSE.txt`（不适用 AGPL-3.0；新加的图标要先写进去）。`python tools/legend_icons.py` 按 `config/legends.json` 的英文名对上编号，去掉编辑信息、四周空白裁成一样多，生成 `panel/static/legends/<编号>.svg`，并把许可文件复制过去（随安装包发）。出了新传奇：放原图、写许可、运行一次

## 按赛季看（2026-11-03，第 31 赛季开始那天用户要求）

- 用户的话："新赛季了，应该从 0 开始记录，给一个按钮选择这赛季还是上赛季"。用户选的：总览页、数据页"我的"的范围按钮"本赛季 / 上赛季 / 近 30 局 / 全部"，**默认本赛季**；战绩页加赛季筛选"本赛季 / 上赛季 / 全部"（没有近 30 局：列表本来就是从新到旧分页的），默认本赛季；数据页"全体玩家"加"本赛季"（默认）；分享的概况卡片不按赛季（照旧近 30 局 / 全部，总览页是赛季时用近 30 局）
- 每个赛季从什么时候开始写在 `config/seasons.json`（官方开赛时刻，UTC；第 31 赛季 2026-11-03 18:00 UTC = 瑞士 19:00 = 北京 11-04 02:00），换成电脑上的时间再比；每局按结束的时间、大厅读数按读到的时间归到赛季（`code/seasons.py`）。配置里没有上一个赛季时没有"上赛季"按钮。新赛季开始时要加一行（见 `docs/底座.md`"新赛季要做的"）
- 按钮悬停写着"第 31 赛季：11/03 起"（上赛季"第 30 赛季：08/04 起，到 11/03"）；默认的那个不写进网址。按钮在卡片标题栏里放不下时换行
- 这个赛季还没有对局（新赛季刚开始）：总览页的最近对局、数据页（不摆一排空卡片）、战绩页的表格里写"本赛季（第 31 赛季：11/03 起）还没有对局，打完一局就会算进来"，下一行"看看上赛季或全部的战绩"（链接）。段位卡片照样显示本赛季读到的段位（回过大厅就有）；统计数字是"—"
- 战绩页网址里没写赛季时：点开某一局（`open`，比如从总览页"最近对局"点进来）看那一局所在的赛季；"只看待确认"看全部赛季（顶部的提醒按全部算，待确认的局可能是上赛季的）。推断出来的赛季在翻页、换筛选时带着

## 总览页

- 段位卡片、RP 走势图：大厅读数比最后一局新时用大厅的（卡片上注明"大厅"），走势图在最后一局之后接上大厅读数
- 走势图：段位按 `config/ranks.json` 里每段的起点换算成连续分数（`ranks.py`；第 30 赛季：黄金 5500 起每段 750，钻石 12000 起每段 1000，大师 16000）；范围内的段位分界线画成虚线并标上段位名；下一段的分数线只在快升段时画，离得远就不画（免得折线被压扁）
- "今日"从早上 5 点算起：打到凌晨的局仍算前一天
- 读不到赛季，范围按钮只有"近 30 局 / 全部"，同时控制走势图、统计数字和传奇表现
- 传奇表现的横条按名次分段上色（冠军 / 第 2–3 / 第 4–10 / 其余），对应设计稿底部的图例
- 统计数字六格（场均名次、场均击杀、场均伤害、前五率、胜率、统计局数）都是一样的颜色：胜率原来用红色标出来，2026-11-19 用户要求不再标红
- 场均击杀不算击杀来自经验值页的局（那种局的击杀是计分次数）
- 顶部的"监测中"状态先不做：面板还不知道记录有没有在跑
- 最下面"关注我"（2026-10-22 用户要求，官网首页结尾也有同样的两个按钮）：开发者的 B 站、小黑盒主页，地址在 `panel_app.FOLLOW_LINKS`（正式地址，不带分享追踪参数）；`target="_blank"` 交给系统浏览器打开，Evo 自己不联网；没有对局时也显示。图标 `panel/static/brands/*.svg` 是用户给的图描成的单色 SVG（商标属于各自的公司），颜色跟随文字

## 战绩页

- 表格：名次、时间、模式、地图、传奇、击杀/助攻/击倒、伤害、生存时间、RP；急救、重生放在展开的详情里
- 点开一局：先只展开两名队友（两行，列和表头对齐，左边连接线连到名次徽章；名字旁写急救、重生，悬停显示 ID；传奇是对局中认出的）；识别截图和修改表单要再点"详情与修改"（网址加 `detail=1`），待确认的局直接全部展开
- 详情里有老板分、RP 从哪来（经验值页 / 对局中右上角 / 大厅校准）；修改表单能改名次、击杀、助攻、击倒、老板分、伤害、RP（还不能改传奇，见 todo.md）
- 确认或删除一局时，删掉这一局的截图

## 录像页（2026-11-20，内测中）
`code/panel_recordings.py`，模板 `recordings.html`（列表）、`recordings_watch.html`（播放），样式在 `style.css`"录像页"一节。录像怎么录见 `docs/录像.md`。
- **导航**：在"战绩"后面，只在设置里打开了录像（`recording_enabled`）或者录像文件夹里已经有录像时才显示（`panel_app.nav_items`；没打开的玩家看不到）。切换页面时底色滑多远按显示出来的导航算
- **列表**：一格一个录像（按内容区的宽度排），从新到旧。缩略图 16:9（录完时截的，最后一个事件前 1 秒；以前的录像第一次打开时用 ffmpeg 截一张存在旁边；截不到时照样占着位置），右下角时长，鼠标指上去出现播放图标；下面传奇（小头像）、模式 · 地图 · 时间、名次徽章、击杀、伤害、事件数。没 .json 的（上次 Evo 崩了拼回来的）标"未完成"、写"没对上战绩"。上面一行：共多大、上限、"打开文件夹"。没有录像时一句说明
- **播放页**：返回、传奇、副标题（模式 · 地图 · 时间 · 时长 · 大小）、对上的那一局（名次、击杀、伤害、"在战绩里看"，点了去战绩页展开那一局）。播放器不自动播放（`preload="metadata"`）。下面自己画的时间轴：已放过的一段、现在的位置（竖线）、断掉的几段（斜线，悬停写"这 N 秒没录到"）、事件标记（按钮：鼠标指上去、键盘移过去时上方显示"倒地 4:02"）。点标记或下面事件列表里的按钮，从事件前 3 秒开始放；点时间轴空白处跳到那里。**时间轴能拖**（2026-11-21 用户要的）：按住移动超过 4 像素才算拖（只点一下照旧是点，标记照样能点），拖的时候先暂停，竖线、已放过的一段和中间的时间跟着手走，画面也跟着换（上一次跳完了才跳下一次）；松手跳到那里，原来在放就接着放；拖出时间轴外也跟着。鼠标指到时间轴上时竖线顶上冒出一个圆头，提示能拖，拖的时候手形是"抓着"。11-21 在浏览器面板里用真实录像试过：拖到中间、点"被复活"标记从前 3 秒放、放着时往回拖松手接着放。网址带 `t=秒` 时从那一刻开始。"在资源管理器中显示"（选中这个文件）、"删除"（先确认：文件名、多大、不能恢复；删之前先让播放器放开文件，不然 Windows 删不掉）
- **挨得很近的事件合成一个标记**（2026-11-21 用户选的，`panel_recordings.group_marks`）：和前一个相隔不到时长的 2.4%（约一个标记宽，10 分钟的录像约 15 秒；至少 1 秒；标记换成图标以后从 1.2% 放宽）的连成一组。合成的标记画其中最要紧的那个的图标（冠军 > 击杀 > 成盒 > 被复活 > 倒地 > 被扶起 > 击倒 > 助攻击倒 > 助攻，`MARK_PRIORITY`：击杀不会被旁边的击倒盖住），右上角一个小圆写个数；悬停写出全部（"6:21 倒地 · 6:22 助攻击倒"），读屏软件念"2 个事件：倒地 6:21，助攻击倒 6:22"；点了从第一个事件前 3 秒开始放。下面的事件列表照样一条一条列，每条都能点
- **事件的颜色**：倒地黄、被扶起绿、成盒红、被复活蓝、冠军紫、击杀红（强调色）、击倒对手橙、助攻击倒琥珀（和击倒一类颜色，2026-11-21 加的）、助攻粉（2026-11-20 加的）；名字照样写着，不只靠颜色分
- **事件的图标**（2026-11-21 用户要的："与其用颜色，可不可以自己画一些图标"）：时间轴上每个标记是一个 22 像素的白底圆（一圈事件的颜色，里面是图标），下面列表每条前面也是图标（以前是一个色块）。图标自己画的（`_rec_icons.html`，24 × 24 线条）：击倒 = 准星、助攻击倒 = 虚线准星、击杀 = 骷髅、助攻 = 握手（用户 11-21 选的，原来是两个圈搭在一起）、倒地 = 向下的箭头落到地面线、被扶起 = 从地面线向上的箭头、成盒 = 死亡之箱（立方体）、被复活 = 绕一圈的箭头、冠军 = 皇冠。颜色照旧（浅色主题图标颜色压暗一点，浅黄、浅粉在白底上也看得清）；时间轴高 32 像素（原来 28）
- **和战绩对上**：按时间（录像的开始时刻 + 时长，战绩里那一局的结束时刻落在里面、往后留 2 分钟）。战绩页有录像的局，传奇后面一个小摄像机按钮（悬停写"看录像"），点了去播放页
- 录像文件 `/recordings/video` 用 Flask 的 `send_file(conditional=True)`：支持 Range，能拖进度条。网址里的录像 id 是"年-月/文件名"，只认录像文件夹里的（不让网址指到别的文件、分段文件夹）

## 分享战绩（2026-10-21）

- 用户决定：三种卡片都做；队友只显示传奇和这一局的数据，不写名字和 ID；自己的游戏名默认显示，分享前能勾掉。不做"分享链接"（要上传到服务器，违反原则 2）
- 入口：战绩页点开一局，"详情与修改"左边的"分享这局"（待确认的局没有：数据还没确认）；总览页段位卡片右上角"分享"（"今日战绩"和"近 30 局概况 / 全部概况"，范围跟着总览页的按钮；今天没打时"今日战绩"不能选；"全部账号"时没有）
- 对话框（`panel/templates/_share.html`）：预览、"在图上显示我的游戏名"（没认出玩家名时不显示这一项）、有待确认的局时提醒"确认后图上的数字更准"、"复制图片"（写进剪贴板，到微信、QQ 里 Ctrl+V）、"保存图片…"（Evo 窗口里弹 Windows 的"另存为"，默认"图片"文件夹，`app_window.save_image`，只收 PNG；用浏览器打开的面板直接下载）
- 卡片（`panel/templates/share/*.svg`，数据在 `panel_app.py` 的"分享战绩"）：SVG 里放一段网页排版（foreignObject），字体、传奇头像、段位图标、Evo 图标都嵌成 data: 网址；页面把它画成 2 倍大小的 PNG（单局、今日 1440×810，概况 1440×1080）。固定用黑夜主题的颜色，不跟随面板主题；右下角"EVO evotracker.cn"
  - 坑：SVG 要用 data: 网址载入再画到 canvas 上；用 blob: 网址载入的话（里面有 foreignObject），浏览器不让导出
  - 坑：写剪贴板要窗口在前台（自动化测试时窗口在后台会报"Document is not focused"）；ClipboardItem 直接交一个还没完成的 Promise，免得生成慢了超过"刚点过按钮"的时限
- 单局：名次（冠军写"冠军"，按名次上色，和徽章一样）、传奇、模式 · 地图 · 日期时间、击杀 / 助攻 / 击倒 / 伤害 / 生存、RP（只有排位局）、打完这局的段位、两名队友的传奇和数据
- 今日：从早上 5 点算起；今日 RP、现在的段位、局数 / 最好名次 / 总击杀 / 总伤害 / 场均伤害、每局名次（最多 16 个，更早的写"前面还有 N 局"）
- 概况：段位、RP 合计、走势图（和总览页同一个 `rp_chart`）、6 个统计数字、传奇表现（最多 3 个 + 其他，两列）。以后能按赛季看了，改成按赛季（见 todo.md）
- 时间写日期（"10月21日 21:30"，不是今年的加年份），不写"今天""昨天"：图片发出去以后过几天再看就不对了
- 读不到的项写"—"；总击杀、总伤害只加读到的局
